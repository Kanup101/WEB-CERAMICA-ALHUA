# Videos

Esta carpeta queda preparada para videos locales cortos del sitio.

## Formatos recomendados

- Usar `.mp4` optimizado para videos breves, livianos y sin reproduccion obligatoria.
- Usar poster en `.webp` o `.jpg` cuando el video sea local.
- Evitar subir videos pesados al repositorio.

## Videos largos

Para clases completas, entrevistas largas o material de cursos, usar servicios externos como YouTube, Vimeo o Cloudinary y embeberlos desde la web.

## Ejemplo de uso futuro

```text
public/videos/proceso-ceramico.mp4
public/images/products/proceso-poster.webp
```

Luego configurar el taller o seccion con `videoUrl`, `videoType` y `videoPoster`.
